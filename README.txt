BAIXADOR DE VÍDEO — ANDROID

O QUE ESTA VERSÃO FAZ
- Recebe links do YouTube.
- Pode receber um link por "Compartilhar" no app do YouTube.
- Baixa vídeo MP4 em melhor qualidade, até 1080p ou até 720p.
- Extrai áudio MP3.
- Mostra progresso.
- Permite cancelar.
- Publica o arquivo em Downloads/Baixador de Vídeo.
- Inclui botão para atualizar o motor yt-dlp.

IMPORTANTE
Este ZIP é o projeto Android completo, não um APK já compilado.

COMO GERAR O APK PELO ANDROID STUDIO
1. Instale o Android Studio.
2. Abra a pasta "BaixadorYouTubeAndroid".
3. Aguarde o Gradle sincronizar e baixar as dependências.
4. Menu Build > Build App Bundle(s) / APK(s) > Build APK(s).
5. O APK de teste ficará em:
   app/build/outputs/apk/debug/app-debug.apk
6. Envie esse APK ao celular e instale.

PRIMEIRO USO
- Abra o aplicativo.
- Aguarde aparecer "Pronto".
- Se um download do YouTube falhar por mudança no site, toque em
  "ATUALIZAR MOTOR DE DOWNLOAD" e tente novamente.

ARMAZENAMENTO
No Android moderno, o download é feito primeiro em uma pasta privada do app
e depois publicado usando MediaStore em Downloads/Baixador de Vídeo. Isso
evita pedir acesso amplo a todos os seus arquivos.

USO
Use apenas para vídeos/conteúdos que você tem direito de baixar.
